# 🤖 EKO - "Studi-Help"

> **La herramienta que necesitás para estudiar y concentrarte.**

## 📖 Descripción del Proyecto
**EKO** es un prototipo de asistente robótico escolar conectado al celular, diseñado como respuesta a la problemática de la desconcentración en las aulas y durante las horas de estudio. 

Su funcionamiento está pensado para mantener el foco de manera simple:
* 🎵 **Modo Concentración:** Reproduce música relajante de fondo mientras no utilizás el teléfono.
* 🚨 **Alerta de Distracción:** Activa una alarma sonora si agarrás el celular antes de terminar tu sesión de estudio.
